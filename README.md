高中國文加考複習 App（手機網頁版，可加到主畫面、可離線使用）。

內容取自講義：
| 模組 | 講義頁碼 | 題數 |
| --- | --- | --- |
| 字形辨識 | p.21–24 | 133 組 |
| 字音填字 | p.31–35 | 262 題 |
| 字根讀音 | p.43–48 | 263 題 |
| 一詞多義 | p.109–113 | 70 個例句 |
| 成語古今義 | p.125–127（33–64） | 32 則 |

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 畫面與樣式 |
| `app.js` | 程式（解析題庫、出題、進度紀錄） |
| `data.js` | **題庫**。修正錯字、新增章節只要改這個檔案，檔案開頭有格式說明 |
| `manifest.webmanifest`、`icons/` | 加到主畫面時的名稱與圖示 |
| `sw.js` | 離線支援 |
| `學生使用指引.md` | 給學生的安裝與使用說明 |

## 用 GitHub Pages 上架

1. 在 GitHub 建立一個新的 repository（例如 `qiangjiu-guowen`），設為 Public。
2. 把這個資料夾裡的所有檔案上傳到 repository 的根目錄（`Add file` → `Upload files`，可整批拖曳）。
3. 到 repository 的 **Settings → Pages**，Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等 1–2 分鐘，頁面上方會出現網址，格式是 `https://<你的帳號>.github.io/<repository 名稱>/`。
5. 把網址貼到學生指引裡發給學生。

## 修改題目

1. 在 GitHub 上打開 `data.js`，按鉛筆圖示編輯，改完按 Commit。
2. 約 1 分鐘後網站就會更新；學生下次有網路時打開 App 就是新版，學習紀錄不會消失。

題庫格式（摘要）：
- `@學113`／`@指106`：歷屆考題標記
- `^文字`：補充說明
- `字{注音}`：在字下方標注音（字形辨識用）

## 加考日期

倒數計時的時間在 `app.js` 中搜尋 `2026-11-23T00:00:00+08:00` 修改。

## 注意

- 學習紀錄存在學生手機瀏覽器（localStorage），不需登入，也不會上傳到任何地方。
- 字型使用 Google Fonts（霞鶩文楷 TC、Noto Sans TC），第一次開啟需要網路。
